# Heraclitus · daily fragment

A tiny Android app whose only job is a home-screen widget: one Heraclitus fragment a day,
tap to flip to a short note. Same fragment each day as the Windows lock-screen version.

- No permissions (no internet, no storage), no ads, no tracking.
- Changes after midnight with a non-waking alarm, so it never wakes the phone.
- Built by GitHub Actions on every push: Actions → latest run → Artifacts → `heraclitus-widget`.

Translations: John Burnet, *Early Greek Philosophy*, 3rd ed. (1920), ch. III, §65, public domain.
Numbers are Burnet's (Bywater's arrangement). Notes are new, not Burnet's.
Fonts: Cormorant Garamond / Cormorant SC, SIL Open Font License (see FONT-LICENSE.txt).
